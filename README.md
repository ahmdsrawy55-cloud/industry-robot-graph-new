# 工业机器人投资网络拓扑图 (自动化发布平台)

本项目是一个专门用于自动生成高颜值“投资网络图谱”的在线程序。
借助于 GitHub Actions，当您上传新的 Excel 数据后，云端服务器会在 30 秒内自动运行 Python 脚本重绘画布，并将最新的交互式网络图免服务器发布到您的专属网页上。

## 📊 核心效果与功能
- **节点自动识别与着色**：“被投公司”与“投资机构”使用极具专业感的低饱和度颜色区分（暖橘粉与蓝青色）。
- **动态大小调节**：投资机构出手次数越多、被投公司融资轮次越频繁，图上的气泡就越大，一眼即辨认行业核心玩家。
- **智能高亮交互**：界面极简抗干扰。点击任意关键节点，瞬间剥离周边噪音（变灰），聚焦并高亮它真实的投资资金流动链路。
- **快速检索过滤**：内置搜索功能，支持通过输入公司或机构名称关键字进行高亮和锁定。

---

## 🚀 后期如何修改数据来更新图表？

本项目采用基于数据驱动的**“零干预更新”**机制。在您配置完成后，未来只需要准备好新的 Excel 表，完全不需要碰任何代码。

### 第 1 步：清洗并整理您的最新 Excel 数据 
请您准备好一份格式为 `.xlsx` 的 Excel 数据源文件，**并确认满足以下 2 条硬性格式要求：**
1. **表头必须包含**：数据表必须包含名为 `Source` 和 `Target` 的两列（区分大小写，英文名不能变）。
2. **两列代表的对象别弄反**：
   - **`Source`** 列：必须放完整的 **【被投公司】** 名称。
   - **`Target`** 列：必须放完整的 **【投资机构】** 名称。

### 第 2 步：在 GitHub 上提替换旧数据 
当您处理完毕，将其保存（或重命名）为 `data.xlsx`。
1. 打开您的 GitHub 仓库主页。
2. 点击进入 **`data`** 文件夹。
3. 在页面右上方，点击 **`Add file`** 下拉菜单，选择 **`Upload files`**。
4. 将电脑上做好的最新 `data.xlsx` 拖拽到虚线框内。
5. 点击页面下方绿色的 **`Commit changes`** 按钮自动覆盖老文件。

### 第 3 步：静静等待 30 秒验收
新表格传进仓库后，GitHub 会立刻在云后台接管一切：
它会自动为您启动 Python、读取您的新 Excel、用新数据重新生成这个庞大的复杂网状图，最后自动推送到线上。
您只需要等待大概半分钟，再去**刷新您的专属网页地址**，即可向别人展示包含最新数据的网状交互图了！
